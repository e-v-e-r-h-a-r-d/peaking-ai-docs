Peaking AI offers a family of models optimized for different tasks, latency requirements, and budgets. All models are accessed through the same API — just change the `model` parameter.

## Model overview

| Model | Context | Best for | Speed | Input cost | Output cost |
|-------|---------|----------|-------|------------|-------------|
| **Peak-1 Pro** | 200K | Complex reasoning, coding, analysis | Moderate | $15 / 1M tokens | $75 / 1M tokens |
| **Peak-1** | 128K | General purpose, chat, content | Fast | $5 / 1M tokens | $25 / 1M tokens |
| **Peak-1 Flash** | 64K | High-volume, low-latency tasks | Ultra fast | $1 / 1M tokens | $5 / 1M tokens |
| **Peak-1 Embed** | 8K | Embeddings, similarity search | Instant | $0.10 / 1M tokens | — |

## Choosing a model

### Peak-1 Pro

Our most capable model. Use it when quality matters most — complex analysis, multi-step reasoning, code generation, and tasks requiring deep understanding.

```python
response = client.chat.create(
    model="peak-1-pro",
    messages=[{"role": "user", "content": "Analyze this architecture for scalability issues..."}]
)
```

### Peak-1

The best balance of speed and capability. Ideal for most production workloads including customer-facing chat, content generation, and data extraction.

```python
response = client.chat.create(
    model="peak-1",
    messages=[{"role": "user", "content": "Summarize this article..."}]
)
```

### Peak-1 Flash

Optimized for speed and cost. Sub-100ms latency for classification, routing, simple Q&A, and high-volume pipelines.

```python
response = client.chat.create(
    model="peak-1-flash",
    messages=[{"role": "user", "content": "Classify this support ticket: ..."}]
)
```

### Peak-1 Embed

Purpose-built for generating text embeddings. Returns dense vector representations for semantic search, clustering, and similarity comparisons.

```python
response = client.embeddings.create(
    model="peak-1-embed",
    input="The quick brown fox jumps over the lazy dog"
)

vector = response.data[0].embedding  # 1536-dimensional vector
```

## Common parameters

All chat models accept these parameters:

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `temperature` | float | 1.0 | Randomness. Lower = more deterministic |
| `max_tokens` | int | 4096 | Maximum tokens in the response |
| `top_p` | float | 1.0 | Nucleus sampling threshold |
| `stop` | string[] | null | Stop sequences to end generation |
| `stream` | bool | false | Enable streaming responses |

:::tip
For production applications, set `temperature` between 0 and 0.3 for consistent, reproducible outputs.
:::
