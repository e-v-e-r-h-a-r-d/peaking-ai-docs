Workflows let you chain multiple AI operations into a single, managed pipeline. Define steps, connect them with logic, and let Peaking AI handle execution, retries, and monitoring.

## Workflow structure

A workflow consists of **steps** connected by **edges**. Each step processes input and produces output that feeds into the next step.

```python
from peaking import PeakingAI

client = PeakingAI()

workflow = client.workflows.create(
    name="Content Pipeline",
    steps=[
        {
            "id": "extract",
            "model": "peak-1-flash",
            "prompt": "Extract the key topics from: {{input}}"
        },
        {
            "id": "research",
            "model": "peak-1-pro",
            "prompt": "Research each topic in detail: {{extract.output}}"
        },
        {
            "id": "write",
            "model": "peak-1-pro",
            "prompt": "Write a comprehensive article: {{research.output}}"
        }
    ]
)
```

## Running a workflow

```python
result = client.workflows.run(
    workflow_id=workflow.id,
    input="The future of renewable energy in 2026"
)

print(result.output)

for step in result.steps:
    print(f"{step.id}: {step.status} ({step.duration_ms}ms)")
```

## Branching logic

Use conditions to create dynamic workflows that route based on intermediate results:

```python
{
    "id": "route",
    "type": "condition",
    "condition": "{{extract.output.topic_count}} > 5",
    "if_true": "summarize_first",
    "if_false": "research_directly"
}
```

## Parallel execution

Run steps concurrently when they don't depend on each other:

```python
{
    "id": "parallel_research",
    "type": "parallel",
    "steps": ["research_topic_a", "research_topic_b", "research_topic_c"],
    "merge": "combine_results"
}
```

## Error handling

Configure retry policies and fallbacks per step:

```python
{
    "id": "critical_step",
    "model": "peak-1-pro",
    "prompt": "...",
    "retry": {
        "max_attempts": 3,
        "backoff": "exponential"
    },
    "fallback": {
        "model": "peak-1",
        "prompt": "Simplified version: {{input}}"
    }
}
```

:::tip
Use Peak-1 Flash for routing and classification steps to minimize latency, and reserve Peak-1 Pro for steps that require deep reasoning.
:::
