Peaking AI Agents are autonomous systems that break down complex tasks, use tools, and iterate until a goal is achieved. Unlike single-turn chat completions, agents maintain state across multiple steps.

## How agents work

An agent operates in a continuous loop:

<Steps>
1. **Observe** — The agent receives a task and analyzes the current state
2. **Plan** — It determines the next action to take
3. **Act** — It executes the action using available tools
4. **Reflect** — It evaluates the result and decides whether to continue
</Steps>

This loop repeats until the task is complete or a termination condition is met.

## Creating an agent

```python
from peaking import PeakingAI

client = PeakingAI()

agent = client.agents.create(
    model="peak-1-pro",
    name="Research Assistant",
    instructions="You are a research assistant that finds and synthesizes information.",
    tools=[
        {"type": "web_search"},
        {"type": "code_interpreter"},
    ],
    max_steps=20
)
```

## Running a task

```python
result = client.agents.run(
    agent_id=agent.id,
    task="Find the top 3 trending AI papers this week and write a summary of each."
)

print(result.output)

for step in result.steps:
    print(f"Step {step.index}: {step.action} -> {step.status}")
```

## Built-in tools

| Tool | Description |
|------|-------------|
| `web_search` | Search the web and retrieve page content |
| `code_interpreter` | Execute Python code in a sandboxed environment |
| `file_reader` | Read and parse uploaded files (PDF, CSV, JSON) |
| `database` | Query connected databases with natural language |

## Custom tools

Define your own tools using JSON Schema:

```python
custom_tool = {
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "Get current weather for a location",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {
                    "type": "string",
                    "description": "City name or coordinates"
                }
            },
            "required": ["location"]
        }
    }
}

agent = client.agents.create(
    model="peak-1-pro",
    tools=[custom_tool],
    instructions="You help users with weather-related questions."
)
```

## Lifecycle management

Monitor and control agent execution:

```python
# Cancel a running agent
client.agents.cancel(run_id=result.id)

# List recent runs
runs = client.agents.runs.list(agent_id=agent.id, limit=10)

# Get run details with full step history
run = client.agents.runs.get(run_id=result.id)
```

:::note
Agents use Peak-1 Pro by default for optimal reasoning. Use Peak-1 for simpler tasks to reduce costs.
:::
