Prompt Studio es el módulo donde defines la personalidad, el tono y el comportamiento de tu agente de IA. Un buen prompt es la diferencia entre una IA que frustra a tus clientes y una que los deleita.

## En esta sección

- **[Crea tu primer prompt](/03-prompt-studio/crea-tu-primer-prompt/)** — Guía paso a paso para empezar desde cero.
- **[Mejores prácticas y ejemplos](/03-prompt-studio/mejores-practicas-y-ejemplos/)** — Prompts reales que funcionan y por qué.
- **[Variables y funciones avanzadas](/03-prompt-studio/variables-y-funciones-avanzadas/)** — Personaliza respuestas con datos dinámicos.
- **[Cómo testear tu agente](/03-prompt-studio/como-testear-tu-agente/)** — Valida el comportamiento antes de activar en producción.

---

:::tip[Buena práctica]
Empieza con un prompt simple y refínalo con base en conversaciones reales. Un prompt de 200 palabras bien escrito supera a uno de 2,000 mal estructurado.
:::
