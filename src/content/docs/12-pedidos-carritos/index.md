El módulo de **Pedidos y Carritos** centraliza todas las transacciones generadas a través del agente de IA — desde el carrito hasta el pago confirmado. Aquí puedes revisar órdenes, gestionar carritos abandonados y configurar las pasarelas de pago.

## En esta sección

- **[Pedidos y Carritos](/12-pedidos-carritos/pedidos-y-carritos/)** — Gestión de órdenes, carritos abandonados y seguimiento de transacciones.
- **[Flujo de compra con IA](/12-pedidos-carritos/flujo-de-compra-con-ia/)** — Cómo el agente guía al cliente desde el producto hasta el pago confirmado.
- **[Conexión con Stripe](/12-pedidos-carritos/stripe-configuracion/)** — Configurar Stripe como pasarela de pago internacional.
- **[Conexión con Mercado Pago](/12-pedidos-carritos/mercado-pago-configuracion/)** — Configurar Mercado Pago para mercados latinoamericanos.
