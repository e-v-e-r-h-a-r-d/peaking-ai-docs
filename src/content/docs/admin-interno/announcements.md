Esta sección es exclusiva para el equipo Peaking. Requiere contraseña de administrador.
:::

**Announcements** es el sistema de comunicados oficiales de Peaking. Los anuncios creados aquí aparecen automáticamente en la parte superior del panel de cada usuario en **app.peaking.ai** — visible para todos los clientes activos.

Úsalo para comunicar mantenimientos programados, lanzamientos de funcionalidades, cambios importantes de política o cualquier mensaje que el equipo Peaking quiera que todos los usuarios vean de forma destacada.

---

## Cuándo usar Announcements

| Caso de uso | Ejemplo |
|-------------|---------|
| **Mantenimiento** | "El sistema estará en mantenimiento el viernes 23 de mayo de 2:00 a 4:00 AM UTC" |
| **Nuevo lanzamiento** | "¡Ya puedes usar Voice Agents! Configúralos en Integraciones › Agentes de Voz." |
| **Cambio de política** | "Actualización de Términos de Servicio — efectiva el 1 de junio." |
| **Aviso operativo** | "Demoras en la sincronización de plantillas de WhatsApp — el equipo está trabajando en ello." |

---

## Cómo funciona

Los anuncios creados aquí se publican en tiempo real y aparecen en la barra superior del panel de la aplicación para todos los usuarios autenticados. El anuncio permanece visible hasta que se desactive o elimine manualmente desde este panel.
