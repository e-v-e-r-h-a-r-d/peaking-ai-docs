This guide walks you through making your first API call to Peaking AI. By the end, you'll have a working integration that generates text from a prompt.

## Prerequisites

- A Peaking AI account ([sign up here](https://console.peaking.ai))
- An API key from the [Console](https://console.peaking.ai/api-keys)
- Node.js 18+ or Python 3.9+

## Setup

<Steps>

1. **Install the SDK**

   <Tabs>
     <TabItem label="Python">
     ```bash
     pip install peaking-ai
     ```
     </TabItem>
     <TabItem label="JavaScript">
     ```bash
     npm install peaking-ai
     ```
     </TabItem>
     <TabItem label="cURL">
     No installation needed. Use any HTTP client.
     </TabItem>
   </Tabs>

2. **Set your API key**

   Store your key as an environment variable:

   ```bash
   export PEAKING_API_KEY="pk-your-api-key"
   ```

3. **Make your first request**

   <Tabs>
     <TabItem label="Python">
     ```python
     from peaking import PeakingAI

     client = PeakingAI()

     response = client.chat.create(
         model="peak-1",
         messages=[
             {"role": "user", "content": "Explain quantum computing in one paragraph."}
         ]
     )

     print(response.choices[0].message.content)
     ```
     </TabItem>
     <TabItem label="JavaScript">
     ```javascript
     import PeakingAI from 'peaking-ai';

     const client = new PeakingAI();

     const response = await client.chat.create({
       model: 'peak-1',
       messages: [
         { role: 'user', content: 'Explain quantum computing in one paragraph.' }
       ]
     });

     console.log(response.choices[0].message.content);
     ```
     </TabItem>
     <TabItem label="cURL">
     ```bash
     curl https://api.peaking.ai/v1/chat/completions \
       -H "Authorization: Bearer $PEAKING_API_KEY" \
       -H "Content-Type: application/json" \
       -d '{
         "model": "peak-1",
         "messages": [
           {"role": "user", "content": "Explain quantum computing in one paragraph."}
         ]
       }'
     ```
     </TabItem>
   </Tabs>

</Steps>

## Understanding the response

The API returns a JSON object with the following structure:

```json
{
  "id": "chat-abc123",
  "object": "chat.completion",
  "model": "peak-1",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Quantum computing leverages the principles of quantum mechanics..."
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 14,
    "completion_tokens": 87,
    "total_tokens": 101
  }
}
```

:::tip
The `usage` field helps you track token consumption for cost management. See [API Reference](/api-reference/overview/) for the full response schema.
:::

## Streaming responses

For real-time output, enable streaming:

<Tabs>
  <TabItem label="Python">
  ```python
  stream = client.chat.create(
      model="peak-1",
      messages=[{"role": "user", "content": "Write a short poem."}],
      stream=True
  )

  for chunk in stream:
      print(chunk.choices[0].delta.content, end="")
  ```
  </TabItem>
  <TabItem label="JavaScript">
  ```javascript
  const stream = await client.chat.create({
    model: 'peak-1',
    messages: [{ role: 'user', content: 'Write a short poem.' }],
    stream: true
  });

  for await (const chunk of stream) {
    process.stdout.write(chunk.choices[0].delta.content ?? '');
  }
  ```
  </TabItem>
</Tabs>
