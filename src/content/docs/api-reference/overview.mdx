The Peaking AI API is a RESTful API that uses JSON for requests and responses. All endpoints are served over HTTPS from `https://api.peaking.ai`.

## Base URL

```
https://api.peaking.ai/v1
```

## Authentication

All requests require an API key passed in the `Authorization` header:

```bash
Authorization: Bearer pk-your-api-key
```

See [Authentication](/get-started/authentication/) for details on creating and managing keys.

## Request format

All request bodies must be JSON with the `Content-Type: application/json` header:

```bash
curl https://api.peaking.ai/v1/chat/completions \
  -H "Authorization: Bearer $PEAKING_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "peak-1",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

## Response format

All responses return JSON with a consistent structure:

```json
{
  "id": "chat-abc123",
  "object": "chat.completion",
  "created": 1712345678,
  "model": "peak-1",
  "choices": [...],
  "usage": {
    "prompt_tokens": 10,
    "completion_tokens": 50,
    "total_tokens": 60
  }
}
```

## Rate limits

Rate limits are applied per API key:

| Tier | Requests/min | Tokens/min |
|------|-------------|------------|
| Free | 60 | 40,000 |
| Pro | 600 | 400,000 |
| Enterprise | Custom | Custom |

When you hit a rate limit, the API returns `429 Too Many Requests` with a `Retry-After` header.

## Pagination

List endpoints support cursor-based pagination:

```bash
GET /v1/agents?limit=20&after=agent_abc123
```

| Parameter | Description |
|-----------|-------------|
| `limit` | Number of items to return (1-100, default 20) |
| `after` | Cursor for the next page |
| `before` | Cursor for the previous page |

## Versioning

The API version is included in the URL path (`/v1/`). Breaking changes are only introduced in new versions. Non-breaking additions (new fields, new endpoints) may be added to existing versions.
