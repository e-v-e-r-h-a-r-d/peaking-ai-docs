## Chat Completions

<span class="method-badge method-post">POST</span> `/v1/chat/completions`

Generate a chat completion from a sequence of messages.

### Request body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `model` | string | Yes | Model ID (`peak-1`, `peak-1-pro`, `peak-1-flash`) |
| `messages` | array | Yes | Array of message objects |
| `temperature` | float | No | Sampling temperature (0-2, default 1) |
| `max_tokens` | int | No | Max tokens to generate (default 4096) |
| `top_p` | float | No | Nucleus sampling (0-1, default 1) |
| `stream` | bool | No | Enable streaming (default false) |
| `stop` | string/array | No | Stop sequence(s) |
| `response_format` | object | No | Force JSON output format |

### Message object

| Field | Type | Description |
|-------|------|-------------|
| `role` | string | `system`, `user`, or `assistant` |
| `content` | string/array | Text content or multimodal content array |

### Example

```bash
curl https://api.peaking.ai/v1/chat/completions \
  -H "Authorization: Bearer $PEAKING_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "peak-1",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "What is the capital of France?"}
    ],
    "temperature": 0.7,
    "max_tokens": 256
  }'
```

## Embeddings

<span class="method-badge method-post">POST</span> `/v1/embeddings`

Generate vector embeddings for text input.

### Request body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `model` | string | Yes | Model ID (`peak-1-embed`) |
| `input` | string/array | Yes | Text to embed (string or array of strings) |
| `encoding_format` | string | No | `float` (default) or `base64` |

### Example

```bash
curl https://api.peaking.ai/v1/embeddings \
  -H "Authorization: Bearer $PEAKING_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "peak-1-embed",
    "input": "Search query text"
  }'
```

## Agents

<span class="method-badge method-post">POST</span> `/v1/agents`

Create a new agent configuration.

<span class="method-badge method-post">POST</span> `/v1/agents/{agent_id}/runs`

Start a new agent run.

<span class="method-badge method-get">GET</span> `/v1/agents/{agent_id}/runs/{run_id}`

Get the status and output of an agent run.

<span class="method-badge method-delete">DELETE</span> `/v1/agents/{agent_id}/runs/{run_id}`

Cancel a running agent execution.
