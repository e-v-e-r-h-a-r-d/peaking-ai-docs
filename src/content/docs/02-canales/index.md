Además de WhatsApp — que por ser el canal de mayor volumen tiene su propia sección dentro de **[Integraciones](/09-integraciones-partner/)** —, Peaking soporta otros canales de mensajería para que atiendas a tus clientes donde sea que te escriban.

## Canales disponibles

| Canal | Artículo |
|-------|---------|
| Instagram (mensajes directos) | [Conexión con Instagram](/02-canales/conexion-instagram/) |
| Facebook Messenger | [Conexión con Messenger](/02-canales/conexion-messenger/) |
| Widget para sitio web | [Widget para sitio web](/02-canales/widget-sitio-web/) |

Una vez conectados, verifica que todo funcione correctamente: [Estado y verificación de canales](/02-canales/prueba-verificacion-canales/).

Si el agente deja de responder en Instagram o Messenger sin ningún otro cambio, probablemente sea un token vencido: [Reconexión de tokens](/02-canales/reconexion-tokens/).

:::
